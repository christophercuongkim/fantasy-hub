## Infra / deploy (all working)
- **Ports:** web `4000`, api `4001` (VPS already uses 80/3000/8000/8080). Container ports in Dokploy Domain settings.
- **Build:** both Dockerfiles build from **repo-root context** (`COPY web/…`, `COPY api/…`). Dokploy apps: Context Path `.`, Dockerfile `web/Dockerfile` / `api/Dockerfile`. compose uses `context: .`.
- **Deploy:** two Dokploy apps (web, api), autodeploy ON. CI `deploy.yml` joins tailnet → curls each app's webhook. Manual: `gh workflow run deploy.yml -f service=both` (or web/api). Merge to main auto-deploys changed service.
- **DB migrations CI** (`db.yml`): PR → Neon preview branch → `drizzle-kit migrate` → schema-diff comment → delete on close; merge → migrate prod (`PROD_DATABASE_URL`).
- **GitHub secrets:** `DOKPLOY_WEB_WEBHOOK`, `DOKPLOY_API_WEBHOOK`, `NEON_API_KEY`, `PROD_DATABASE_URL`, `TS_OAUTH_CLIENT_ID`, `TS_OAUTH_SECRET`. **Variable:** `NEON_PROJECT_ID`.
- **Domain:** target `fantasy.chriskim.cloud` (A record → VPS IP, DNS-only if Cloudflare; ports 80/443 open). Yahoo OAuth callback `https://fantasy.chriskim.cloud/api/auth/yahoo/callback`.
