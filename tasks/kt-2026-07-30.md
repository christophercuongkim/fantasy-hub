## How we work (full detail in root `CLAUDE.md`)
- Every non-trivial change: **surface design calls in chat → get yes/no → branch `feat|fix|chore|docs/<name>` off `origin/main` (rebase) → commit → PR → line-anchored self-review → STOP for Chris's manual review.** Don't merge; don't start the next PR's code while one waits.
- **Doc-only PRs self-merge** (`docs/**`, `*.md`, `CLAUDE.md`, `tasks/**`, memory, `.gitignore`).
- **No AI-attribution trailers** in commits/PRs.
- **Commit from inside the dev shell** (`nix develop --command git ...`) — pre-commit hooks shell out to pnpm/uv/ruff. Commits often abort because prettier/ruff reformat staged files — **re-`git add` the reformatted files and re-commit** (check `git log`, not the hook output).
- **Pushing** may need `GIT_SSH_COMMAND='ssh -o StrictHostKeyChecking=accept-new'` and running with the sandbox disabled; pre-push runs `pytest (api)`.
- Chris consistently picks the more thorough option.

## Gotchas / lessons (also `tasks/lessons.md`)
- Yahoo scraping: manual login (2FA); `make scrape-auto`/`--attach` (real browser) because weekly matchups lazy-load; scraped data is gitignored PII under `bootstrap/data/`.
- `defense_vs_pos` rank 1 = allows the MOST = best matchup (data-dictionary invariant).
- Make treats a bare `#` as a comment — escape `\#` in flake/nix refs.
- Migrations: timestamp filenames; `db.yml` CI runs a Neon preview per PR, migrate-prod on merge.
- Local end-to-end verify uses an ephemeral Postgres (`nix shell nixpkgs#postgresql`, port 5433) + screenshots via headless chromium (`--virtual-time-budget` to let animations settle).
